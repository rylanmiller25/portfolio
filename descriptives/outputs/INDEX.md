## Folder Structure

```
outputs/
  figures/    ← generated figures (.png or .pdf)
  posts/      ← LinkedIn post drafts (.md), named to match figure slug
  INDEX.md    ← this file
```

## Naming Convention

Each deliverable uses a shared slug: `[number]-[short-description]`

Example:
- `figures/01-tpm-prior-experience-google.png`
- `posts/01-tpm-prior-experience-google.md`
